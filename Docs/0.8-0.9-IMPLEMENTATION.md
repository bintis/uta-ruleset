# 0.8 / 0.9 implementation and remaining integration work

## Baseline defects addressed

1. **Configuration-key drift:** historical settings are assigned explicit values 0-22. Microphone monitor output is migrated to appended key 23, preventing another config-manager instance from interpreting a later setting under the wrong numeric key.
2. **Auto not entering formal scoring:** Auto now emits 20 ms synthetic analysis frames through `UtaGameplayScoringController.Enqueue`, so native judgements, HUD and results consume one path.
3. **Runtime scoring-option drift:** Transpose/OCT changes start a new timeline epoch, reset the streaming session and mark the run non-comparable rather than scoring old and new options together.
4. **PCM completion race:** queue completion is atomic; producer/channel races return rented buffers; disposal is shared/idempotent and drains every pending block.
5. **Unsafe import error surface:** full exceptions remain in logs, while the user view receives a bounded, path-stripped category and message.

## 0.8 architecture

`UtaRemoteServer` owns network lifetime and credentials. `UtaRemoteGameplayBridge` is the only command target and schedules every mutation onto the gameplay thread. `UtaRemoteProtocol` owns parsing and bounds. `UtaRemoteSecurity` owns tickets, sessions, replay guards, rate limits and network policy. `UtaRemoteControlOverlay` requires explicit service start and creates controller/spectator links. The single HTML client stores reconnect credentials only for the current tab and converges on server snapshots.

## 0.9 architecture

The mobile client has a Rust `no_std` protocol helper compiled to WASM. The build script embeds it into a single HTML file. The checked-in fallback module has the same exported ABI for source-packaging environments without Rust; release CI rebuilds with Rust before the .NET build, then validates the generated single-file asset and exported ABI.

`UtaSkinComponentLookup` provides ruleset-native lookup identifiers for grid, notes, song/live curves, playhead, lyrics, score feedback and particles. The transformer asks the active lazer skin first and returns accessible defaults when omitted. Configuration lookups expose colours, line weight, spacing and animation intensity. `UtaAccessiblePalette` restores minimum contrast when a custom colour is unsafe.

Imported packages already use lazer's native video event, which inherits gameplay-clock seek/pause/rate synchronisation. This overlay adds stable settings for visibility, dim, blur and offset, but the final drawable binding must be verified against the exact target lazer background/video hierarchy rather than implemented by reflection.

## Deliberately open acceptance items

- native desktop QR rasterisation (the one-time pairing URL is complete);
- visual replacement of every existing hard-coded pitch/lyrics primitive with a skinnable lookup;
- exact video drawable binding for ruleset-only dim/blur/offset;
- complete English/Japanese/Chinese migration of all historical desktop strings;
- real-device LAN, firewall/URL-ACL, mobile browser and accessibility passes;
- long-session audio/recording/device hot-plug soak tests.

These are listed as open because this package could not run the target host, not hidden behind a “complete” checkbox.
